JUSO AJLA - SEO verzija

FAJLOVI ZA GITHUB ROOT:
- index.html
- admin.html
- robots.txt
- sitemap.xml
- CNAME
- site.webmanifest
- assets/ (cijeli folder)

BITNO:
1. Na GitHubu zamijeni postojece index.html i admin.html ovim verzijama.
2. Uploaduj robots.txt, sitemap.xml, CNAME i site.webmanifest u root repozitorija.
3. Zamijeni /assets folder ovim assets folderom (ili dodaj/overwrite fajlove).
4. Ne mijenjaj Cloudflare DNS zapise niti GitHub Custom Domain.
5. Nakon deploya otvori https://jusoajla.ba u incognito modu ili ocisti cache.
6. Zatim dodaj https://jusoajla.ba/sitemap.xml u Google Search Console.

SEO ukljucuje: canonical, robots, Open Graph/Twitter, LocalBusiness/AutoPartsStore schema, FAQ schema, lokalni tekst za Kalesiju/Zivinice/Tuzlu, alt tekstove i sitemap slika.
Mixed-content zastita: dodat je Content-Security-Policy upgrade-insecure-requests; svi postojeći eksterni resursi u dostavljenom kodu su vec bili HTTPS.
